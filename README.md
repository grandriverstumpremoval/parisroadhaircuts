# Paris Road Haircuts

Single-page, static website for Paris Road Haircuts in Paris, Ontario. Built with Astro and configured for Netlify.

## Run locally

Install Node.js 22.23.5 or newer, then run:

```sh
npm install
npm run dev
```

Create and preview the production build with:

```sh
npm run build
npm run preview
```

The static site is generated in `dist/`. `netlify.toml` sets the build command, publish directory, and Node.js version for Netlify.

## Business details and photos

The page uses the business's public phone, address, pricing, and profile links. Hours are not shown as a fixed schedule; visitors are asked to call or message to confirm current availability.

The included Unsplash photos are licensed stock images and are labeled as illustrative, not as photos of the salon or its work. Replace them with business photos only when you have permission to publish those photos.
